# Mermaid Lightbox

An Obsidian community plugin that opens Mermaid diagrams in a large modal viewer.

## Features

- Click a rendered Mermaid diagram to open it in a modal
- Mouse wheel zoom in and out
- Zoom percentage indicator
- `Fit` button to reset back to fit-to-window
- Double click to reset zoom
- Left-drag to pan when zoomed in

## Plugin Info

- Plugin ID: `mermaid-lightbox`
- Author: `yzxcxy`

## Files

- `manifest.json`: Obsidian plugin metadata
- `main.js`: plugin logic
- `styles.css`: modal and viewer styles

## Usage

1. Open any note with a rendered Mermaid diagram.
2. Click the diagram to open the viewer.
3. Use the mouse wheel to zoom.
4. Click `Fit` or double click to reset.
5. When zoomed in, hold the left mouse button and drag to pan.

## Notes

- This plugin is designed for local use inside the current vault.
- After changing plugin files, restart Obsidian or reload the plugin to apply updates.
